# SolidCraft on iPad: device build

An Xcode project (generated by [xcodegen](https://github.com/yonaskolb/XcodeGen)) that wraps the Rust
`solidcraft-ios` binary and adds `SolidCraftAI.framework`: Apple on-device AI (FoundationModels), the Claude
API tier, and an offline Qwen3 4B tier (MLX). The Rust side loads the framework with `dlopen`.

Needs Xcode 26+, an iPad or iPhone on iPadOS/iOS 26, `brew install xcodegen`, and the Rust target
`rustup target add aarch64-apple-ios`.

```
DEVELOPMENT_TEAM=<your Apple team id> BUNDLE_ID=<unique id, e.g. com.example.solidcraft> \
  ./build_device.sh <device UDID>          # xcrun devicectl list devices
```

A free personal team works, but its provisioning profile expires after 7 days (rebuild to renew).
The Claude tier needs your own Anthropic API key, entered in the app and stored in the Keychain. The
offline model (about 2.3 GB) is downloaded once from Hugging Face on request.

Docs: [`../docs/ai-test-prompts.md`](../docs/ai-test-prompts.md) (prompts and ratings),
[`../docs/IPAD_PRO_REQUESTS.md`](../docs/IPAD_PRO_REQUESTS.md) (the "Ask Claude (Pro)" file-bundle flow).
